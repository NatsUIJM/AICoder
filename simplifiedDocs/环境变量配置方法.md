# 环境变量配置方法

该教程用于说明如何在 Windows 和 macOS 系统中配置环境变量。

## Windows

1. 右键点击开始菜单，选择"终端管理员"。
2. 运行如下命令：

```powershell
[Environment]::SetEnvironmentVariable("变量名", "变量值", "User")
```

## macOS

1. 打开"终端"App。
2. 运行如下命令：

```bash
echo 'export 变量名="变量值"' >> ~/.zshrc
```

3. 然后使更改生效：

```bash
source ~/.zshrc
```
