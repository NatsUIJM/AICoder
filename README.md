# AICoder

## 这个专栏是干什么的？
省流：本专栏教你如何真正利用大语言模型编程，**学习周期短，无需学习编程语言，零收费，切实可行**。如果你确实有这方面的需求，请简单看看下面这一小段话。

在程序设计这一任务中，将思路转化为代码只是一部分工作，而这部分确实可以被如今迅速发展的大语言模型（LLM）所取代。然而，对于大部分非计算机科学相关专业的人而言，在拿到 LLM 生成的代码后，第一个问题往往是："我该怎么运行这玩意？"

程序设计作为提升生活和工作效率的利器，长期以来因为编程语言学习这道高门槛阻碍了大多数人。如今 LLM 已经能够解决这个最大障碍——只需几句话（例如，请给我使用 Python 写一个能加减乘除的计算器）就能快速得到可运行的 Python 源代码。但配置开发环境、管理生成的代码等必不可少的技术细节，现阶段的 LLM 并不能独立完成，而这些内容又缺乏系统化的教程。

本专栏旨在填补这一空白，通过 3 个循序渐进的项目实例，来讲述一种不依赖编程语言学习的全流程解决方案，让更多人能够借助 LLM 的力量，轻松设计并实现有实用价值的程序。
## 具体的学习路径？
本专栏包括七个部分的内容：
- 第一部分讲述开发环境配置，这是完成后续工作的必要准备
- 第二部分到第六部分将循序渐进地讲述开发一个 Python 程序的一般流程
- 第七部分是番外篇，讲述使用 JavaScript 开发简单浏览器插件的方法

在讲第二部分到第六部分具体的内容之前，需要先讲讲程序设计的基本流程，它包括开发、设计和分发三个步骤。其中：
1. **开发是指开发程序的核心运行流程**（例如，开发一个简单的计算器应用，需要编写代码实现加减乘除等基本功能。这部分主要关注程序的核心逻辑，如何接收两个数字并返回正确的计算结果）
2. **设计是指设计用户界面**（继续计算器的例子，你需要设计按钮布局、显示屏、颜色方案等元素，确保用户能够方便地输入数字、选择运算符，并清晰地看到计算结果）
3. **分发是指把这个你设计好的程序分享给别人**（完成计算器应用后，你可能会将它打包上传到应用商店，或者放在自己的网站上供人下载，也可能通过邮件直接发送给朋友使用）

回到具体学习路径：
- 第二部分到第四部分通过循序渐进的三个案例，讲述三个步骤中的**开发**部分，提出一种模块化、理论上可无限扩展其功能的程序设计思路；
- 第五部分基于第四部分所给出的案例，讲述两种相对简单的用户界面**设计**方法；
- 第六部分基于第四、五部分所给出的案例，讲述两种相对简单的程序**分发**方法。

在这里说这些不是为了让你记住它们，而是对这个专栏要讲述的内容有基本的概念。在完成全部六个部分后，你才能真正理解这个路径。如果只想学习如何开发浏览器插件，也可以直接跳转到第七部分。
## 你可能关心的其他问题？
1. **是否需要程序设计基础？**
   答：完全不需要编程知识，虽然有基础的读者可能上手更快。事实上我到现在也一行代码都不会写，但是并不妨碍我开发 [autoContents](https://github.com/NatsUIJM/autoContents) 这个实用的项目。
2. **现在 AI 编程这个专题是割韭菜的重灾区，这专栏是不是也是其中的一份子？**
   答：首先这个专栏**完全免费也没有广告，在物理上堵死了割韭菜的可能性**。内容方面，本专栏会搭建一个完整的程序设计体系，这个体系用的是模块化设计思路，理论上可以无限扩展它的功能。上面提到的 autoContents 工具就是用这个体系开发出来的，只不过模块有些多，不太适合用来教学，所以没选它作案例。
3. **使用到的工具是否有访问限制？**
   答：本教程使用 Cherry Studio、DeepSeek-v3 和 VSCode 组合。它们的官方网站均可在中国大陆正常访问，并且仅 DeepSeek API 调用会产生少量费用，其余工具均为免费资源。别担心，后面会教你怎么配置它们。
4. **学会了能赚钱吗？**
   答：本教程可以让你做一个完整的程序出来，但是这是纯技术内容，并不包含任何商业变现方案。换句话说，我会教你如何做产品，但是不会教你怎么把它卖出去，因为我自己也不会。
